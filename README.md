# Северный Свет

Статический сайт производственной компании: 8 страниц, адаптивная вёрстка, собственный набор SVG-иконок, найденные логотипы клиентов и изображения ImageGen.

Без сборки и зависимостей — только HTML, CSS и один файл JavaScript.

## Запуск

```sh
npm run dev
```

Откройте http://localhost:4173. Нужен Python 3; установка зависимостей не требуется.

Альтернатива без npm:

```sh
python3 -m http.server 4173 --directory dist
```

Проверка JavaScript: `npm run check`.

## Публикация на Vercel

Сборки нет, публикуется папка `dist` как есть. Настройки лежат в `vercel.json`:
выходная папка, слеш в конце адресов и кэш на файлы в `/assets`.

```sh
npx vercel        # предпросмотр
npx vercel --prod # боевой адрес
```

Через веб-интерфейс: импортируйте репозиторий, Framework Preset — **Other**,
Build Command оставьте пустым, Output Directory — `dist`. Файл `vercel.json`
задаёт это сам, вручную менять ничего не нужно.

Адреса страниц — папки с `index.html` (`/services/`, `/price/` и так далее),
поэтому переписывание путей не требуется.

## Дизайн

Светлая база как в референсе: белый фон, тёмно-синий текст, бирюза северного
сияния в акцентах и тёплая охра на ценах. Тёмные острова — финальный призыв,
подвал и крупная карточка на фотографии; они получают класс `on-dark`, который
переопределяет те же переменные, поэтому компоненты не дублируются.

Палитра, размеры и тени собраны в `:root` в начале `dist/style.css` — менять
оформление удобнее всего там.

- Заголовки — **Unbounded**, текст и интерфейс — **Onest**, технические подписи,
  индексы разделов и таблицы — **JetBrains Mono**. Все три с кириллицей,
  подключаются с Google Fonts.
- Иконки — один набор в `dist/app.js`. Интерфейсные знаки взяты из Lucide (ISC),
  производственные и отраслевые нарисованы для проекта на сетке 24×24.
  Оригиналы Lucide лежат в `dist/assets/icons/`.
- Фирменный знак — встроенный SVG (`brandMark` в `dist/app.js`), не растровая обрезка.

## Где редактировать

- `dist/app.js` — тексты, состав страниц, карточки, навигация, формы, иконки и поведение.
- `dist/style.css` — дизайн-система, размеры, адаптив, анимации.
- `dist/assets/` — изображения, SVG-логотипы и иконки.
- `dist/index.html` и `dist/*/index.html` — каркасы страниц. При изменении каркаса
  правьте все восемь одинаково.

Формы готовят письмо в почтовом приложении пользователя. Серверная отправка и CRM
не подключены. Контакты, цены и числа перенесены из референсов. Изображения
проектов — визуализации, а не фотографии выполненных работ.

## Известное ограничение

Изображения лежат в PNG: около 16 МБ всего и примерно 9 МБ на главной. Для
боевого адреса их стоит перевести в WebP или AVIF — вес страницы упадёт в 5–10 раз.
